# Runbook: Wildcat Hub SIS sync

Covers the four things the brief asks for: re-running a failed sync, rolling
back a bad load, who to contact when credentials expire, and rotating the
client secret.

Written 2026-08-12. **Nobody has read this but its author**, which is itself a
go/no-go line. Second reader needed.

## What runs, and when

| | |
|---|---|
| Schedule | Twice daily, 13:00 and 19:00 UTC (06:00 and 12:00 PT) |
| Where | Convex, deployment `quick-cassowary-644`, `convex/crons.ts` |
| What it calls | `sisAction:syncFromPowerSchool` |
| Source | `lapf.powerschool.com`, plugin id 9741 |
| Read only | Only the OAuth token request and POSTs to named query paths |

The clock is UTC, so the local time shifts an hour at the DST boundary. Both
runs stay inside the school day either way.

## Check whether the last sync worked

```
export CONVEX_DEPLOY_KEY=$(op read 'op://Employee/Westbrook WildCats Hub/Convex wildcat-hub-ci Deploy Key')
npx convex run sisStats:stats '{}'
```

Healthy looks like roster rows in the thousands, `rosterStudents` around 641,
and a recent `lastSyncedAt`. `syncLog:latest` has the last five run summaries.

`gradeRowsMissingPercent` equal to `gradeRows` is EXPECTED right now: the 26-27
year began 2026-08-12 and no grades are posted. It is a gap, not a zero, and
must never render as 0%.

## Re-run a failed sync

Safe to run any time. Roster is a full replace, students upsert on student
number, and nothing it writes is earned value.

```
npx convex run sisAction:syncFromPowerSchool '{"reason":"manual re-run"}'
```

Locally, with more output and a dry-run option:

```
cd powerschool/sync
npm run sync -- --dry     # pull and report, write nothing
npm run sync              # for real
```

## Roll back a bad load

There is no snapshot restore for Convex here, so rollback is "re-sync from the
source", which works because PowerSchool is authoritative for everything the
sync writes.

1. Re-run the sync. Roster and grades are full replaces, so a bad load is
   overwritten rather than merged with.
2. If student identity looks wrong, re-run and check `sisStats:stats`.
3. **Balances are never touched by a sync**, so they cannot be damaged by one.
   If a balance looks wrong, the sync is not the cause; check `npm run drift`
   against Firestore.

⚠️ **Untested.** This path has never been rehearsed on real damage. That is a
go/no-go line still open.

## Credentials

| Secret | Where |
|---|---|
| PowerSchool client id | `op://Employee/Westbrook WildCats Hub/SIS Client ID` |
| PowerSchool client secret | `op://Employee/Westbrook WildCats Hub/SIS Client Secret` |
| Convex deploy key | `op://Employee/Westbrook WildCats Hub/Convex wildcat-hub-ci Deploy Key` |

All three are also set as Convex deployment environment variables, which is
what the scheduled sync reads. **Changing one in 1Password does not change it
in Convex.** Both have to be updated.

### When PowerSchool credentials expire or stop working

Symptom: `PowerSchool auth failed: HTTP 401` in the sync run.

Contact: the PowerSchool / SIS administrator for LA Promise Fund. The plugin is
"Wildcat Hub Sync", id 9741. Credentials are issued by PowerSchool when the
plugin is enabled, and are regenerated by disabling and re-enabling it.

### Rotate the client secret

1. PowerSchool: System > System Settings > Plugin Management Configuration >
   Wildcat Hub Sync. Disable, then re-enable. PowerSchool issues a new secret.
2. Update 1Password: `SIS Client Secret` on the `Westbrook WildCats Hub` item.
3. Update Convex, so the scheduled sync uses it:
   ```
   npx convex env set PS_CLIENT_SECRET "$(op read 'op://Employee/Westbrook WildCats Hub/SIS Client Secret')"
   ```
4. Verify: `npx convex run sisAction:syncFromPowerSchool '{"reason":"post-rotation check"}'`

Never paste a secret into a file, a commit, or a chat. The repo is public.

## When something looks wrong

| Symptom | First thing to check |
|---|---|
| Sync ran, roster count dropped sharply | A term rolled over. `PS_TERM_ID` and `PS_YEAR_TERM_ID` are pinned per term and go stale each year. |
| All grades empty | Expected before grades are posted. Confirm with the `terms` query. |
| A teacher sees no roster | Their Entra email must match `psRoster.teacherEmail`. Check `npx convex run seed:staffAuthReadiness '{}'`. |
| A student cannot sign in | Expected. Student email does not exist in the SIS at all. |
| Balances look wrong | Not the sync. Run `npm run drift`. |
